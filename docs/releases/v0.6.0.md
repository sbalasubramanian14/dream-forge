# Dream Forge v0.6.0 — developer preview

Dream Forge is a local, interactive 3D particle canvas for Codex, Claude Code and other tool-using agents. This GitHub release packages the CLI, stdio MCP server and installable skills. Marketplace plugins and npm publishing are not included.

## Install

Requires Node.js 22+, npm, an installed agent CLI and a WebGL-enabled browser.

```sh
git clone --branch v0.6.0 --depth 1 https://github.com/sbalasubramanian14/dream-forge.git
cd dream-forge
node scripts/setup.js codex
node bin/dream-forge.js doctor codex
```

Use `claude` for Claude Code or `cli` for standalone use. You can also extract the source ZIP and run setup from that directory. Restart the agent after registering MCP/installing the skill, then ask: “Use Dream Forge to show A–Z in a fresh canvas.”

For trusted Codex canvas operations without repeated write-tool prompts, explicitly add `--approve-canvas` to setup. This changes only Dream Forge's local canvas-tool policies; other tool/server approvals remain unchanged. Without it, the host's existing approval policy applies.

## What's new

- Guided setup resolves local paths and installs locked dependencies, MCP and skills.
- Doctor checks a disposable MCP connection, scene delivery and browser assets without touching saved canvases.
- `show_text`/`text` render letters and digits directly, with validation and compact responses. Agents no longer need a custom glyph generator.
- Installed skills record exact entrypoints in `installation.json` and prefer the text fast path.
- Bubble sort is a bundled 14-step example with comparisons, swaps, final positions and early exit.
- README now includes first use, update/uninstall instructions, screenshots, configuration and honest limits.
- The attached WebM records the actual headed application: formation, sorting, steps, solar system and inspection.

## Update

Stop the old server, fetch tags, check out this release, and repeat setup with `--update`. Refresh project skill copies separately, restart agent MCP connections and refresh browser tabs. Saved-canvas format is unchanged from 0.5.0; history remains in the existing local data directory.

See the [README](https://github.com/sbalasubramanian14/dream-forge/tree/v0.6.0#readme) for complete update and uninstall commands.

## Validation and limits

Verified locally with 20 runtime tests, 11 headed Chromium tests, a clean-clone bootstrap, actual Codex/Claude CLI registration in isolated settings, and a fresh Codex session using the global skill/MCP installation. The fresh session created a canvas and called `show_text` successfully without repository searching or writing a generator. Model startup and host approval settings still affect total response time.

Procedural particles are illustrative, not Gaussian reconstruction or physical simulation. Maximums: 24 objects, 48 connections, 20 steps, 1 MiB compact JSON. Browser graphics still require WebGL; doctor checks assets, not GPU compatibility. macOS has not been independently tested.
